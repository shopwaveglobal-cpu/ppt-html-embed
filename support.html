1im HTML Player

PowerPoint 슬라이드 안에 인터랙티브 HTML을 넣어, 발표 중에 클릭·입력·애니메이션이 그대로 동작하게 합니다.

사용법

  1. 삽입 → 추가 기능 → 1im HTML Player를 슬라이드에 넣습니다.
  2. 생긴 창을 원하는 크기(보통 슬라이드 전체)로 늘립니다.
  3. HTML 파일을 창에 끌어놓거나 클릭해서 고릅니다. 또는 https 주소를 입력합니다.
  4. 슬라이드쇼에서 HTML 화면을 한 번 클릭하면 키보드가 연결됩니다. 이후 클릭·화살표 키가 HTML로 전달됩니다.
  5. 내용을 바꾸려면 편집 화면에서 창 오른쪽 위 ⚙ 버튼을 누릅니다.

자주 묻는 질문

HTML은 어디에 저장되나요?
PowerPoint 파일 안에 저장됩니다. 외부 서버로 전송되지 않습니다.

다른 PC에서도 되나요?
그 PC의 PowerPoint에도 1im HTML Player가 추가되어 있어야 합니다. 인터넷 연결이 필요합니다.

이미지가 안 보여요.
HTML 안의 이미지는 base64로 넣거나 https 주소로 연결해야 합니다. 내 PC 폴더 경로는 불러올 수 없습니다.

저장이 안 돼요.
아주 큰 HTML(수 MB 이상)은 저장되지 않을 수 있습니다. 이 경우 https 주소 방식을 사용하세요.

Support (English)

Insert 1im HTML Player on a slide, resize it, then drop an HTML file (or enter an https URL). The HTML is saved inside the PowerPoint file. In Slide Show, click the content once to give it keyboard focus. Use the ⚙ button in edit view to replace the content.
