1im HTML Player

PowerPoint 슬라이드 안에 인터랙티브 HTML을 넣어, 발표 중에도 클릭·입력·애니메이션이 그대로 동작하게 합니다. HTML 내용은 PPT 파일 안에 저장됩니다.

1. 지원 환경

PowerPoint방법
Microsoft 365 / Office 2021 이상 (Windows·Mac)설치 (3번)
웹 PowerPoint (powerpoint.office.com)manifest 업로드 (2번)
Office 2019 이하미지원 → 웹 PowerPoint 사용

2. 웹 PowerPoint

  1. powerpoint.office.com 로그인 → 새 프레젠테이션
  2. 홈(또는 삽입) 탭 → 추가 기능 → 추가 기능 더 보기 → 내 추가 기능 업로드 → manifest.xml

3. 데스크톱 PowerPoint

Windows

  1. 배포 zip을 압축 해제 → PowerPoint 완전히 종료
  2. install-windows.cmd 오른쪽 클릭 → 관리자 권한으로 실행
  3. PowerPoint 실행 → 삽입 탭 → 내 추가 기능 → "개발자 추가 기능" 또는 "공유 폴더" → 새로 고침 → 1im HTML Player → 추가

수동(공유 폴더) 방식

  1. C:\1im-addin 폴더에 manifest.xml 넣기 — 영문 경로만 사용
  2. 폴더 속성 → 공유 → 고급 공유 → 공유 이름 1im-addin
  3. 파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 신뢰할 수 있는 추가 기능 카탈로그 → \\내PC이름\1im-addin 추가 → "메뉴에 표시" 체크
  4. PowerPoint 재시작 → 삽입 탭 → 내 추가 기능 → 공유 폴더 → 새로 고침

Mac

  1. install-mac.command 오른쪽 클릭 → 열기
  2. 삽입 → 추가 기능 → 내 추가 기능 → 개발자 추가 기능 → 1im HTML Player

4. 사용법

  1. 창을 슬라이드 크기로 늘리고 HTML 파일을 끌어놓기 (또는 https 주소 입력)
  2. 슬라이드쇼에서 HTML을 한 번 클릭하면 키보드가 연결됩니다 (첫 클릭은 넘어가지 않음)
  3. 내용 교체: 편집 화면에서 창 오른쪽 위 ⚙

5. 안 될 때

목록에 안 보이면: PowerPoint 완전 종료 → %LOCALAPPDATA%\Microsoft\Office\16.0\Wef 폴더 비우기 → 재시작 → 삽입 → 내 추가 기능 → 새로 고침

"추가"가 회색이면: 새 빈 프레젠테이션에서 시도 / 보안 센터 → 개인 정보 옵션 → "선택적 연결된 경험 사용" 켜기

HTML이 깨지면: ⚙ → 하단 "실행 엔진"이 빨간 글씨(IE11·구형 Edge)면 미지원 PowerPoint → 웹 PowerPoint 사용

이미지가 안 보이면: HTML 안에 base64로 넣거나 https 주소로 연결

Support (English)

Supported: PowerPoint on the web, PowerPoint for Microsoft 365 / 2021 or later (Windows, Mac). Office 2019 and earlier are not supported.

Insert 1im HTML Player on a slide (Insert tab → My Add-ins), resize it, then drop an HTML file or enter an https URL. The HTML is saved inside the PowerPoint file. In Slide Show, click the content once to give it keyboard focus. Use ⚙ in edit view to replace the content. If the add-in is not listed: quit PowerPoint, clear %LOCALAPPDATA%\Microsoft\Office\16.0\Wef, restart and press Refresh.
