1im HTML Player 개인정보처리방침

시행일: 2026-11-22 · 제공자: {{PUBLISHER}} (@1im.lab)

1. 수집하는 정보

1im HTML Player는 사용자의 개인정보를 수집하지 않습니다. 회원가입, 로그인, 분석 도구, 광고, 쿠키를 사용하지 않습니다.

2. 사용자가 넣은 HTML의 처리

사용자가 슬라이드에 넣은 HTML 파일은 Microsoft Office의 문서 설정 기능을 통해 해당 PowerPoint 파일 안에만 저장됩니다. 제공자의 서버나 제3자에게 전송·보관되지 않습니다. 사용자가 https 주소를 입력한 경우, 해당 주소의 웹페이지가 사용자의 PowerPoint 안에서 직접 열립니다.

3. 호스팅

추가 기능의 화면(플레이어)은 GitHub Pages를 통해 제공됩니다. 페이지를 불러올 때 GitHub가 일반적인 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 GitHub의 개인정보처리방침을 따릅니다.

1im HTML Player Privacy Policy

Effective: 2026-11-22 · Provider: {{PUBLISHER}} (@1im.lab)

1. Information we collect

1im HTML Player does not collect any personal information. It uses no accounts, sign-in, analytics, advertising, or cookies.

2. HTML you add

HTML files you add to a slide are stored only inside that PowerPoint file using Office document settings. They are never sent to or stored on the provider's servers or any third party. If you enter an https URL, that web page is loaded directly inside your PowerPoint.

3. Hosting

The add-in page is served from GitHub Pages. GitHub may process standard access logs (such as IP addresses) under GitHub's own privacy statement.
