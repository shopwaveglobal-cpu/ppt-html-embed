1im HTML Player 설명서
=====================
PowerPoint 슬라이드 안에 인터랙티브 HTML을 넣고, 발표 중에도 클릭·입력·애니메이션이 그대로 동작하게 합니다.
HTML 내용은 PPT 파일 안에 저장됩니다. (외부로 업로드되지 않음)


1. 내 PowerPoint는 어떤 방법으로 쓰나요?
--------------------------------------------------
  ● Microsoft 365 / Office 2021 이상 (Windows·Mac)  → 3번(설치) 진행
  ● 웹 PowerPoint (powerpoint.office.com)            → 2번 진행
  ● Office 2019 이하                                 → 2번(웹 PowerPoint) 사용
      (2019는 추가 기능이 구형 엔진으로 실행되어, 대부분의 최신 HTML이 화면만 깨진 채 동작하지 않습니다)

  ※ 버전 확인: PowerPoint → 파일 → 계정


2. 웹 PowerPoint (설치 없음)
--------------------------------------------------
  1) powerpoint.office.com 에 Microsoft 계정으로 로그인 → 새 프레젠테이션
  2) 홈(또는 삽입) 탭 → 추가 기능 → 추가 기능 더 보기
  3) "내 추가 기능 업로드" → 이 폴더의 manifest.xml 선택 → 업로드
  → 4번으로

  ※ 업로드 정보는 그 브라우저에만 저장됩니다. 다른 브라우저를 쓰거나 캐시를 지우면 다시 업로드하세요.


3. 데스크톱 PowerPoint 설치 (PC마다 한 번)
--------------------------------------------------
  먼저 zip 파일을 통째로 압축 해제하세요. (zip 안에서 바로 실행하면 안 됩니다)
  PowerPoint는 완전히 종료한 상태에서 설치하세요.

  [3-A] Windows — 자동 설치
    1) install-windows.cmd 를 마우스 오른쪽 클릭 → "관리자 권한으로 실행"
       (파란 경고창이 뜨면 "추가 정보" → "실행")
       - 관리자 권한이 없으면 그냥 더블클릭해도 됩니다 (개발자 추가 기능 방식만 설정됨)
    2) 창에 "DONE"이 나오면 PowerPoint 실행
    3) 삽입 탭 → 내 추가 기능 →
         "개발자 추가 기능"  또는  "공유 폴더" → 새로 고침
       → 1im HTML Player 선택 → 추가
    → 4번으로

    설치 창에 [WARN] 이나 RESULT: ... failed 가 나오면 → 3-B

  [3-B] Windows — 수동 설치 (공유 폴더 방식)
    1) C:\1im-addin 폴더를 만들고 manifest.xml 을 넣습니다
       - 경로·폴더 이름은 반드시 영문으로 (한글 경로 X)
       - 탐색기 보기 → "파일 확장명" 체크 후, 이름이 정확히 manifest.xml 인지 확인 (.xml.txt 아님)
    2) 1im-addin 폴더 마우스 오른쪽 → 속성 → 공유 탭 → "고급 공유"
       → "선택한 폴더 공유" 체크, 공유 이름: 1im-addin → 확인
       → 네트워크 경로 \\내PC이름\1im-addin 을 메모 (공유 탭에 표시됨)
    3) PowerPoint → 파일 → 옵션 → 보안 센터 → 보안 센터 설정
       → 신뢰할 수 있는 추가 기능 카탈로그
       → 카탈로그 URL에 \\내PC이름\1im-addin 입력 → "카탈로그 추가"
       → 목록에서 "메뉴에 표시" 체크 → 확인 → 확인
    4) PowerPoint 완전히 종료 → 다시 실행
    5) 삽입 탭 → 내 추가 기능 → "공유 폴더" → 새로 고침 → 1im HTML Player → 추가
       (홈 탭의 "추가 기능" 버튼이 아니라 삽입 탭의 "내 추가 기능"입니다)

  [3-C] Mac
    1) install-mac.command 를 마우스 오른쪽 클릭 → 열기 → 열기
       (처음 한 번 보안 경고가 뜨는 건 정상)
    2) "완료!"가 나오면 PowerPoint 실행
    3) 삽입 → 추가 기능 → 내 추가 기능 → 개발자 추가 기능 → 1im HTML Player


4. HTML 넣기
--------------------------------------------------
  1) 슬라이드에 생긴 1im HTML Player 창을 슬라이드 크기만큼 늘립니다
  2) HTML 파일을 창에 끌어놓거나, 점선 영역을 클릭해서 고릅니다
     (예시로 이 폴더의 예시_1im-promo.html 을 넣어 보세요)
  3) 끝. 내용이 PPT 파일 안에 저장됩니다 → 파일만 공유하면 됩니다
  4) 내용을 바꾸려면 편집 화면에서 창 오른쪽 위 ⚙ 버튼 (슬라이드쇼에서는 숨겨짐)

  ※ 슬라이드마다 다른 HTML을 넣을 수 있습니다
  ※ https 주소로 불러오는 것도 가능 (⚙ → 주소 입력 → 불러오기)


5. 발표할 때
--------------------------------------------------
  - 슬라이드쇼에서 HTML 화면을 한 번 클릭 → "⌨ 키보드 연결됨"
    (첫 클릭은 화면을 넘기지 않고 키보드만 연결합니다)
    그 다음부터 클릭·화살표 키가 HTML로 전달됩니다
  - 키보드가 연결되기 전 화살표를 누르면 PowerPoint가 다음 슬라이드로 넘깁니다
    → HTML 슬라이드 뒤에 마무리 슬라이드를 하나 두세요 (마지막 장이면 쇼가 꺼짐)
  - 발표 PC(또는 브라우저)에도 2번이나 3번 설치가 되어 있어야 합니다
    (설치 안 된 PC에서는 정지 화면만 보임)
  - 인터넷 연결이 필요합니다
  - 중요한 발표라면 시연 녹화 영상을 백업 슬라이드로 넣어 두세요


6. 안 될 때 점검표
--------------------------------------------------
  [목록에 1im HTML Player가 안 보임]
    1) PowerPoint 완전히 종료 (작업 관리자에서 POWERPNT.EXE 없는지 확인)
    2) Win+R → %LOCALAPPDATA%\Microsoft\Office\16.0\Wef 입력 → 폴더 안 내용 전부 삭제
    3) PowerPoint 재시작 → 삽입 → 내 추가 기능 → 새로 고침
    4) 그래도 없으면 3-B(공유 폴더 방식)로 진행
    5) 회사 PC에서 "내 추가 기능" 자체가 막혀 있으면 회사 정책입니다 → 웹 PowerPoint 사용

  ["추가" 버튼이 회색]
    - 새 빈 프레젠테이션에서 시도 (호환 모드 .ppt / 제한된 보기에서는 불가)
    - 파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 개인 정보 옵션 → 개인 정보 설정
      → "선택적 연결된 경험 사용" 켜기

  [창은 뜨는데 HTML이 깨지거나 안 움직임]
    - ⚙ → 설정 화면 맨 아래 "실행 엔진" 확인
      "Edge WebView2" / "Safari(WebKit)" / "Chromium" → 정상 환경
      빨간 글씨(IE11·Edge 구형) → 이 PowerPoint는 지원 안 됨 → 웹 PowerPoint 사용

  [HTML 안 이미지가 안 보임]
    - 이미지는 HTML 안에 base64로 넣거나 https 주소로 연결해야 합니다 (내 PC 경로 X)

  [저장 실패]
    - 수 MB 이상의 큰 HTML은 저장이 안 될 수 있습니다 → https 주소 방식 사용


7. 제거
--------------------------------------------------
  Windows: uninstall-windows.cmd 실행 (관리자 권한 권장)
  Mac    : uninstall-mac.command 실행
  웹     : 추가 기능 → 내 추가 기능 → … → 제거
  ※ 이미 만든 PPT 안의 HTML은 그대로 남습니다
