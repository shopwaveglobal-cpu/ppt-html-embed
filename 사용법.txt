1im HTML Player - PPT 슬라이드에 인터랙티브 HTML 넣기
====================================================

[처음 한 번만] 설치
  Windows : install-windows.cmd 더블클릭 (파란 경고창 → 추가 정보 → 실행)
  Mac     : install-mac.command 우클릭 → 열기 → 열기
  → PowerPoint 완전히 종료 후 다시 열기

[매번] HTML 넣기
  1. 삽입 > 추가 기능 > 내 추가 기능 > 개발자 추가 기능 > 1im HTML Player
  2. 생긴 창을 슬라이드 크기만큼 늘리기
  3. HTML 파일을 창에 끌어놓기 (또는 클릭해서 선택)
     → 내용이 PPT 파일 안에 저장됨. 파일만 보내면 됨
  4. 바꾸고 싶으면 창 오른쪽 위 ⚙ 클릭 (슬라이드쇼에서는 숨겨짐)

[발표 PC 체크리스트]
  - 그 PC에도 위 설치를 한 번 해야 함 (안 하면 정지 화면만 보임)
  - 인터넷 연결 필요
  - Windows: Microsoft 365 또는 Office 2021 이상
  - 슬라이드쇼 중 HTML 화면을 한 번 클릭해야 키보드가 HTML로 감
  - 만일을 위해 시연 녹화 영상을 다음 슬라이드에 백업으로 넣어두기

[주의]
  - HTML 안에 이미지·폰트를 base64로 넣거나 https 주소로 연결해야 함
    (내 PC 폴더의 이미지 파일 경로는 안 보임)
  - 아주 큰 HTML(수 MB 이상)은 저장이 실패할 수 있음 → https 주소 방식 사용
