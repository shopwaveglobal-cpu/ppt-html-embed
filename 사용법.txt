1im HTML Player — PPT 슬라이드에 인터랙티브 HTML 넣기
====================================================

지원 환경 (둘 중 하나)
  [트랙 1] 웹 PowerPoint (powerpoint.office.com) — 무료 Microsoft 계정이면 OK, 가장 쉬움
  [트랙 2] PowerPoint for Microsoft 365 (Windows / Mac) 또는 Office 2021 이상
  ※ Office 2019 이하는 미지원 (구형 엔진이라 최신 HTML이 동작하지 않음)

──────────────────────────────
[트랙 1] 웹 PowerPoint
  1. powerpoint.office.com 로그인 → 새 프레젠테이션
  2. 홈(또는 삽입) → 추가 기능 → 추가 기능 더 보기
  3. 내 추가 기능 업로드 → manifest.xml 선택 → 업로드
  ※ 브라우저에 기억됨. 다른 브라우저/캐시 삭제 시 다시 업로드

[트랙 2] Microsoft 365 데스크톱 (PC마다 한 번)
  Windows : install-windows.cmd 더블클릭 (파란 경고창 → 추가 정보 → 실행)
  Mac     : install-mac.command 우클릭 → 열기 → 열기
  → PowerPoint 완전히 종료 후 다시 열기
  → 삽입 > 추가 기능 > 내 추가 기능 > 개발자 추가 기능 > 1im HTML Player

  Windows에서 개발자 추가 기능이 안 보이면 (공유 폴더 방식)
    a. C:\1im-addin 폴더에 manifest.xml 넣기 (확장자 .xml 확인)
    b. 폴더 우클릭 → 속성 → 공유 → 공유 → 네트워크 경로(\\PC이름\1im-addin) 복사
    c. PowerPoint 파일 → 옵션 → 보안 센터 → 보안 센터 설정
       → 신뢰할 수 있는 추가 기능 카탈로그 → 경로 붙여넣고 카탈로그 추가 → "메뉴에 표시" 체크
    d. PowerPoint 재시작 → 삽입 > 내 추가 기능 > 공유 폴더 > 1im HTML Player

──────────────────────────────
[공통] HTML 넣기
  1. 생긴 창을 슬라이드 크기만큼 늘리기
  2. HTML 파일을 창에 끌어놓기 (또는 클릭해서 선택)
     → 내용이 PPT 파일 안에 저장됨. 파일만 보내면 됨
  3. 바꾸고 싶으면 창 오른쪽 위 ⚙ (슬라이드쇼에서는 숨겨짐)

[발표 PC 체크리스트]
  - 그 PC(또는 브라우저)에도 추가 기능을 한 번 넣어야 함
  - 인터넷 연결 필요
  - 설정 화면 아래 "실행 엔진"이 빨간 글씨면 지원 안 되는 PC → 웹 PowerPoint 사용
  - 슬라이드쇼 중 HTML을 한 번 클릭하면 키보드 연결 (첫 클릭은 넘어가지 않음)
  - HTML 슬라이드 뒤에 마무리 슬라이드 하나 두기 (키가 PPT로 가도 쇼가 안 꺼짐)
  - 만일을 위해 시연 녹화 영상을 백업 슬라이드로

[주의]
  - HTML 안의 이미지·폰트는 base64로 넣거나 https 주소로 연결
  - 아주 큰 HTML(수 MB 이상)은 저장 실패 가능 → https 주소 방식 사용
